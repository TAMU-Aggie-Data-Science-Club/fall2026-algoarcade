## Context
RL and the LLM are compared on identical save states, with one manifest. TRN-03 and AGT-02 use seg_01 and seg_02 this week, so capture and share those first. ENV-08 and AGT-04 use the full set.

## Deliverable
Nine FireRed states, captured on rev 0 with MgbaBackend:
- S0: the bedroom on a new game, regenerated by a recorded input script that replays the intro.
- S1: just after delivering Oak's Parcel, with Squirtle.
- seg_01 to seg_05: house, Pallet to Route 1, rival battle, Route 1 to Viridian, Viridian Forest.
- The Pewter Gym door, and the start of the Brock battle.

Every state has text speed fast and battle scene off, set in the options menu.

A manifest in the FireRed folder under `src/algoarcade/games/` lists each state's SHA-256, goal predicate over GameState and step budget. The files live in `data/states/` on each machine, and you hand them to members directly.

## Acceptance criteria
- [ ] `uv run pytest -k state_manifest` passes in CI: nine entries, each with a hash, a callable goal predicate and a step budget.
- [ ] A documented command hashes every file in `data/states/` against the manifest. Its nine OK lines are pasted in the pull request.
- [ ] Replaying the S0 script from power-on gives a bedroom state, map (4,1), that passes the reader's options check.
- [ ] A test (skipped without the ROM) asserts each goal predicate is False on its own start state. For seg_01 to seg_05 it is True on a goal state captured by hand.
- [ ] `git ls-files data/` prints nothing, and docs/setup.md says where to download the states.

## Notes
Contract: docs/harness-spec.md, section Start states and segments.

Gotchas: FireRed defaults to text mid and battle scene on. Report whether two S0 replays hash the same.

Step budgets are guesses: a multiple of your own playthrough's decision count.

A rev 0 state on a rev 1 ROM is untested. Expect it to fail.

Send the files privately and never post them in a public place: save states hold game data, and the repository is public.
