# fall2026-algoarcade — team structure

Who is on this project and how changes reach `main`.
This file replaces `CODEOWNERS`: the merge gate is branch protection, not code-owner review.

## Members

_None assigned yet._

Members have write access: create a branch, push it, and open a pull request.
Members cannot write to `main`; a PM or an officer merges.

## How a change reaches `main`

1. Branch off `main` (`git switch -c your-change`).
2. Push the branch and open a pull request.
3. A PM reviews and merges it.

`main` is protected: only the `fall2026-algoarcade-pm` team and club officers can write to it.
Force pushes and branch deletion are disabled.
